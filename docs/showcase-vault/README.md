# Atlas Research

> [!tip] A living knowledge base
> This small vault shows how ordinary Obsidian notes become a searchable, linked, presentation-ready site with VaultPub.

Atlas Research is a fictional field notebook for a team studying resilient urban systems. Every page is a plain Markdown file. The links, graph, search index, and presentation view are generated from those files at publish time.

## The publishing loop

![[assets/publishing-workflow.svg|900]]

The source stays local. Edit a note, refresh the browser, and the published view updates through VaultPub's live development workflow. #atlas #workflow

> [!note] Designed for real notes
> The showcase intentionally mixes compact notes with a longer research page so navigation, table of contents, backlinks, local graph, and hover previews all have useful content to discover.

## A small, connected corpus

- **Five notes** form a deliberately connected graph.
- **Four shared tags** make tag nodes visible in the graph.
- **One local SVG** is published as an attachment and embedded above.
- **One slide deck** is sourced directly from a normal Markdown note.

The [[Research/Signal Quality|signal quality study]] is the best page for trying the local graph. The [[Guides/Obsidian Patterns|syntax gallery]] is the best page for checking rendering details.
