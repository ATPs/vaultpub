# Feature: Slide Mode

## Goal

Add Reveal.js Presentation Mode as a source-faithful alternate view for published Markdown notes in Django and the standalone ASGI server.

## Conclusion

Implemented core slide segmentation, reusable renderer integration, live presentation routes, Reveal frontend assets, tests, documentation, and a manual demo fixture. Folder-deck heading links now remain correct across slide fragments through note-scoped anchor namespaces. Static-export presentation pages, speaker notes, and advanced split controls remain deferred.
